# [DEPRECATED] iOS nRF Memfault Library + Example App

> [!NOTE]  
> The purpose of this repository has been integrated into the expanded [iOSMcuMgrLibrary Package](https://github.com/NordicSemiconductor/IOS-nRF-Connect-Device-Manager). All functionality previously available via this library has been moved to the newer [iOSOtaLibrary](https://github.com/NordicSemiconductor/IOS-nRF-Connect-Device-Manager?tab=readme-ov-file#iosotalibrary), which is a superset of the previous `iOSMemfaultLibrary`.

# Library

Please transition to [iOSMcuMgrLibrary Package](https://github.com/NordicSemiconductor/IOS-nRF-Connect-Device-Manager), wherein you can now import `iOSOtaLibrary` and have access to a newer version of the library.

# Example App

[Example app](https://apps.apple.com/gt/app/nrf-memfault/id1641119282) has been updated to iOS / iPadOS 26.0 as well as to use the new `iOSOtaLibrary` as both an Example of transition as well as a testbed to confirm the newer library is valid.
